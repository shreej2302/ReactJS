# 📝 React To-Do App

A simple and responsive To-Do list application built with ReactJS.  
Users can add, complete, and delete the tasks.

## 🚀 Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Responsive and beginner-friendly code

## 🛠️ Tech Stack

- ReactJS (via Create React App)
- JavaScript (ES6)
- HTML/CSS

## 📦 Installation

```bash
git clone https://github.com/shreej2302/ReactJS.git
cd react-todo-app
npm install
npm start
